## Uso obrigatório

Todos os modelos documentais do Coala One devem usar este arquivo como autoridade visual, incluindo solicitação de ASO, formulário para a contabilidade, contratos, termos e declarações.

O sistema deve:

1. preservar o modelo original sem alterações;
2. trabalhar em uma cópia durante o preenchimento;
3. gerar a saída final exclusivamente em PDF;
4. disponibilizar o PDF para visualização e aprovação antes do envio;
5. armazenar a versão do modelo e o hash do PDF gerado;
6. preservar cada geração e cada arquivo enviado para auditoria;
7. nunca sobrescrever documentos históricos quando o papel timbrado for atualizado.

## Características verificadas

- Página A4 em orientação retrato.
- Marca Coala Shakes em rosa e azul-claro no canto inferior direito.
- Área central livre para o conteúdo dos documentos.
- Uma seção, sem tabelas, formulários ou texto preexistente.
- A marca está ancorada no corpo do modelo e posicionada atrás do conteúdo.

## Versionamento

Uma atualização do papel timbrado deve gerar um novo arquivo versionado, por exemplo `papel-timbrado-coala-shakes-v2.docx`. Documentos antigos continuam vinculados à versão utilizada na geração.
