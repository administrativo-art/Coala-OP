## Limites transversais

- TV física adiada pelo usuário; integrações Auth/e-mail/Bizneo/PDV/Autentique/bancos sem homologação real nesta entrega.
- Sete achados [A08](surface-audit.md) adiados; falta de correção não impede usar os mapas para localizar código.
- Correções locais anteriores de patrimônio, estoque, RH, heartbeat e claims não foram incorporadas; conferir [diferenças](main-map-integration.md).
- Inventário de arquivo não valida todos os métodos/ramos de uma rota coringa, configurações remotas de scheduler ou extensões Firebase.
- Testes isolados, referências válidas e indicação de permissão na interface não comprovam autorização ponta a ponta.
