# Instrucoes do Projeto

Esta pasta concentra instrucoes operacionais para o Codex e para rotinas assistidas do sistema.

As regras gerais de CLI, limpeza obrigatoria de scripts temporarios e limites para pagamentos bancarios ficam em [AGENTS.md](../AGENTS.md).

## Arquivos

- [populacao-compras-codex.md](./populacao-compras-codex.md): regras para lancar compras a partir de prints, comprovantes e informacoes fornecidas pelo usuario.
- [procedimento-folha-encargos-individualizacao.md](../docs/procedimento-folha-encargos-individualizacao.md): regra obrigatoria para registrar recibos, FGTS, INSS e consignados com vinculo ao colaborador, a competencia e ao RH.
