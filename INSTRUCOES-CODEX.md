# Instrucoes para o Codex

## Compras lancadas pelo assistente

- Toda compra criada pelo Codex deve entrar como `Criada`, nunca como `Confirmada`.
- Nao gerar recebimento automaticamente para compras lancadas pelo Codex.
- Nao gerar financeiro confirmado ou pago automaticamente para compras lancadas pelo Codex.
- Mesmo quando o print indicar pagamento aprovado, a confirmacao da compra deve ser feita manualmente pelo usuario no sistema.
- Ao popular compras a partir de prints, registrar numero do pedido, data, forma de pagamento, status visto no print e observacoes relevantes no campo de notas.
- Se houver duvida sobre fornecedor ou insumo, preferir perguntar antes de criar cadastro novo ou vincular a um cadastro aproximado.
